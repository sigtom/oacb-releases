# Reporting security concerns

Use this repository's **Security → Report a vulnerability** option for a
private report. Include the OACB version, affected feature and reproduction
steps using fictional data.

Do not put pull secrets, BMC or proxy passwords, kubeconfigs, private keys,
customer certificates, generated installer workspaces or customer bundles in
public issues. Redact hostnames, addresses and identifying customer details
from ordinary bug reports. Do not test against systems you are not authorized
to operate.
