# Repository instructions

This is OACB's public distribution repository. Keep it small: customer
instructions, fictional examples and approved release assets. Application
source and builds are maintained separately.

The owner explicitly chose a single `main` branch, direct maintainer updates,
no branch protections, no GitHub Actions and no runners. Do not add a `dev`
branch, CI scaffolding or infrastructure integrations without a new request.

Before publishing, review the exact files and release artifacts for credentials,
customer data, private infrastructure details and redistribution requirements.
Use only fictional examples. Never copy internal source history, runbooks,
issues, build logs or credentials here. Image releases must preserve the
approved app/proxy pair and its exact digests; do not rebuild to publish.

Documentation changes do not authorize customer deployments or BMC operations.
Do not claim a release exists or an installation is proven without evidence.
